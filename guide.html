Mac 安装手册

从一台没有 PlayCover 的 Mac，到在「应用程序」里双击《重返未来：1999》。

开始前安装工具导入游戏部署与启动登录与更新彻底卸载

开始前

打开苹果菜单  →「关于本机」，确认芯片是 Apple M 系列。项目的实测组合是 macOS 26.x、PlayCover 3.1.0、国服 4.0.0（build 210）。首次进入游戏可能还要下载约 22 GB 资源，制作导入包也需要临时磁盘空间。

已经 clone 好了？ 保留这个仓库文件夹。后面提到的 安装.command 就在本页旁边，回到 Finder 双击即可。第一次装从下一节开始；要先清掉旧环境，跳到彻底卸载。

先准备游戏版本。2026 年 11 月 24 日核对时，国服商店返回的是 4.1.0。全新 Mac 需要自己持有兼容版本的游戏副本，或等项目适配当前商店版。本机刚做过完整卸载时，可在废纸篓的 R1999-卸载-…/Applications 找到原有的 重返未来：1999.app，将它拖回 Finder 的「应用程序」，然后从下节安装 PlayCover。系统可能要求管理员确认。这里取回的是 App Store 安装文件，游戏资源会在重装后重新下载。国服 App Store 页面

怎样在仓库目录打开终端？

按 ⌘ 空格，搜索并打开「终端」。输入 cd 和一个空格，把 Finder 中的仓库文件夹拖进终端，按回车。再输入 ./r1999 --help，看到用法即表示目录正确。

安装工具

  1. 装苹果命令行工具。 打开「终端」，粘贴下面一行并按回车。在系统弹窗中点「安装」，等它完成。如果提示已经安装，继续下一步。 
    xcode-select --install
  2. 装 PlayCover。 打开发行页，在 Assets 中下载 PlayCover_3.1.0.dmg。双击磁盘映像，把 PlayCover 拖到「应用程序」。然后从「应用程序」打开它，直到看见应用资料库。PlayCover 3.1.0 发行页 · 官方安装图解

导入游戏

从 Mac App Store 安装的国服游戏开始

  1. 如已取回原有 4.0.0 游戏，跳到下一步。商店提供兼容版本时，在 Mac App Store 用自己的 Apple ID 搜索「重返未来：1999」，选择国服 iPad 版并安装。等 Finder 的「应用程序」里出现 重返未来：1999。
  2. 在仓库文件夹双击 安装.command。看到「将从你的 App Store 游戏副本准备本机导入包」后按回车。它会读取游戏版本、编译项目并在仓库的 build 文件夹生成 国服-本机导入.ipa。Mac 导入副本省略了 iOS 推送通知扩展。这个文件仅供本人在本机导入。
  3. Finder 会选中新生成的文件。把它拖到 PlayCover 的应用资料库，等游戏图标出现。右键游戏打开设置，保存一次，以便下一步配置登录输入。
如果商店提供的是新版本：准备程序会显示实际 build。当前仓库只为 build 210 提供这条本机打包路径；需要对应版本的适配才能继续。
我已经有可导入的 IPA，或者 PlayCover 已经装好了游戏

把自己已有的兼容国服 IPA 拖进 PlayCover，等游戏出现在资料库，再进入下一节。如果图标已经存在，直接进入下一节即可。普通 App Store 下载的加密 IPA 不能直接拖入使用。PlayCover 官方导入说明

部署与启动

  1. 如果游戏正在运行，按 ⌘Q 退出。回到仓库，再次双击 安装.command。这次它会显示「已经找到 PlayCover 中的游戏」，按回车开始部署。
  2. 等终端出现 「安装完成」。打开 Finder →「应用程序」→ 重返未来：1999（PlayCover）。可把这个入口拖到 Dock，之后直接点它启动。
  3. 看到游戏窗口后，点登录页的手机号框试着输入。文字出现、光标能够移动，就完成了。
双击脚本没有运行，或终端里出现红色报错

先在仓库目录打开终端，运行下面的命令查看完整提示。如果提示缺少 PlayTools，请在 PlayCover 的游戏设置中启用 PlayTools，重新导入游戏，再运行安装程序。

bash ./安装.command

登录与更新

账号框点不进去

完全退出游戏，在 PlayCover 打开该游戏的设置，保存一次。在仓库目录依次运行以下命令。重新打开后再点手机号框。

./r1999 controls native && ./r1999 start

需要恢复 PlayCover 键位时，退出游戏，运行 ./r1999 controls mapped 后重启。

更新项目补丁

退出游戏，在仓库目录运行下面一行。它会拉取当前分支并重新部署。成功后从原来的 Finder 入口启动。

./r1999 update

更新游戏本体

先确认新游戏版本有对应补丁，再将自己的新版兼容 IPA 导入 PlayCover，退出游戏并运行 ./r1999 update。若提示版本不兼容，记录游戏版本并等待适配。仅想检查当前组件和签名时运行 ./r1999 verify。

彻底卸载

要从头重装，先确认账号可以重新登录。以下步骤会清掉本地资源和登录状态，重装后需要重新下载。想保留其他 PlayCover 游戏时，保留共享的 PlayCover 容器和 PlayTools。

  1. 退出并移除入口。按 ⌘Q 退出游戏。在仓库目录运行下方命令。它仅移除本项目建立的 Finder 链接。 
    ./r1999 uninstall
  2. 移除游戏及其数据。在 PlayCover 资料库右键该游戏，选卸载；如果出现数据保留选项，选择删除游戏数据。退出 PlayCover。在 Finder「应用程序」中将 App Store 原版移到废纸篓，并从 Dock 移除旧入口。
  3. 移除 PlayCover。将「应用程序」里的 PlayCover 移到废纸篓。如果装在个人应用程序目录，按 ⇧⌘G，输入 ~/Applications，找到对应应用。
  4. 清掉共享组件和项目数据。在 Finder 按 ⇧⌘G，逐项前往下面列出的路径，核对名称后将对应项目移到废纸篓。已有其他 PlayCover 游戏时，第一行容器包含它们的安装包与设置。
查找本地残留
  • PlayCover 共用：~/Library/Containers/io.playcover.PlayCover、~/Library/Frameworks/PlayTools.framework。
  • 国服数据：前往 ~/Library/Containers，在 Finder 核对游戏名称。macOS 有时给容器分配 UUID，应按名称核实归属。前往 ~/Documents 检查游戏写入的 ResLib、logicLog、logicLog.old 和 XfPayReport.sqlite。
  • 缓存和偏好：在 ~/Library/Caches、~/Library/Preferences、~/Library/HTTPStorages 和 ~/Library/WebKit 中，检查与 com.bluepoch.m.reverse1999 或 io.playcover.PlayCover 对应的项目。
  • 旧副本和安装包：检查 ~/Library/Application Support/r1999/Backups.noindex、仓库内的 build、下载目录中的 DMG 和自己生成的 IPA。要继续使用本手册可保留仓库源码。

现在可以回到安装工具重新开始。移到废纸篓的文件仍占磁盘空间；确认无需恢复后，再从废纸篓删除本次卸载的项目。
